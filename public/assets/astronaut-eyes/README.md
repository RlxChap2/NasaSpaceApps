# Astronaut eyes sprite v1

Generated with the built-in image generation tool from the user-supplied astronaut reference. Photorealistic generated character, not footage of a real person.

eyes-sprite-v1.png contains 5 columns and 7 rows (35 frames), read left to right, top to bottom.

Rows 1–5: gaze grid, from upward to downward; columns from viewer-left to viewer-right. Row 3, column 3 is neutral.

Rows 6–7: blink closing and reopening sequence.

This is a generated prototype atlas. Small differences in face registration, gaze spacing, and tile boundaries remain; inspect and align crops before production animation. More frames alone will not remove those differences.

The complete generation prompt is in generation-prompt.txt.
